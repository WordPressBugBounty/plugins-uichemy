**Build Anywhere. Own It In WordPress.**

Start from a prompt, a client brief, a Figma design, or an AI build. [UiChemy](https://uichemy.com/?utm_source=wordpress&utm_medium=readmepage&utm_campaign=uichemy) turns it into native, editable WordPress you own, in the builder you already use.

### Building For WordPress Should Not Mean Building Twice

Three things go wrong on the way from an idea to a live WordPress site, and each one means doing the same work twice.

- **The layout gets rebuilt by hand.** Whatever you designed or generated is assembled a second time once it reaches WordPress. Same structure, same spacing, same decisions, made again on every project.
- **The output cannot be edited.** Many tools return an iframe, a locked template, or markup sealed inside a closed format. It renders correctly and it cannot be maintained, so every small change comes back to you instead of going to whoever owns the site.
- **The page does not live on your site.** When content is rendered from somewhere else, it is not in your database, not in your backups, and not something you can hand to another developer or move to different hosting.

### What UiChemy Does Instead

UiChemy converts your design into WordPress using a single **UiChemy Composer** widget, an AI first visual editor that holds real HTML, CSS and JavaScript.

You add that one widget, once. Every section you build from then on is genuine code stored in your own database, on your own hosting, rendered natively inside your builder. Plain web standards any developer can read, with a visual editor over the top so you can change every line of it.

Not a screenshot of a design. Not an embed. Not a format only we can open. The marquee still slides. The accordion still opens. Nothing stops working because a subscription lapsed.

Rated 4.9 out of 5 and used by 90,000+ designers, freelancers and agencies.

== 1. Figma to WordPress ==

[Figma to WordPress](https://uichemy.com/?utm_source=wordpress&utm_medium=readmepage&utm_campaign=uichemy) converts any Figma design into editable WordPress. No rebuild, no lock-in.

UiChemy reads your frames, layers and Auto Layout the way you built them, then rebuilds the page inside your builder as a UiChemy Composer section holding real HTML, CSS and JavaScript. Your structure carries across and every part of it stays editable.

### How It Works

1. **Design In Figma** : Build in Auto Layout, following the [Design Guidelines](https://uichemy.com/help/design-guidelines/?utm_source=wordpress&utm_medium=readmepage&utm_campaign=uichemy)
2. **Run The Figma Plugin** : Pick your frame and export it straight from Figma
3. **Connect Your Site** : Link your WordPress domain once, then reuse it on every project
4. **Hit Import** : The page opens in your builder ready to edit, not ready to rebuild

### What You Get

- **Global Style Sync** : Figma colours and type become reusable classes in your builder's global settings, so a brand tweak is one change instead of forty
- **Responsive Output Manager** : Set breakpoint rules once and stop hand-fixing every mobile view after import
- **Precise Layer Mapping** : Tag a layer to the exact element you want, so the output matches your intent
- **Modern Image Handling** : WebP, AVIF and SVG files import with the page
- **Bulk And Copy Paste Import** : Push a whole site in one run, or paste a single section with its media attached

### Classic Mode And AI Express Mode

**Classic Mode** is the precision path. Tag layers to specific elements before exporting for output you can predict to the pixel.

**AI Express Mode** is the finishing path. No tagging. It reads every layer and applies motion, hover states, responsive breakpoints, global colours and type, then builds your header and footer during the conversion. It runs on Elementor, and Gutenberg and Bricks use Classic Mode.

Get the Figma plugin for your builder: [Figma to Elementor](https://www.figma.com/community/plugin/1265873702834050352), [Figma to Gutenberg](https://www.figma.com/community/plugin/1379733208974981538/uichemy-convert-figma-to-gutenberg-block-editor-wordpress), or [Figma to Bricks](https://www.figma.com/community/plugin/1344313361212431142/).

== 3. AI to WordPress ==

[AI to WordPress](https://uichemy.com/?utm_source=wordpress&utm_medium=readmepage&utm_campaign=uichemy) moves any AI build into real, editable WordPress. Keep the design, lose the lock-in.

You built something in Claude, Cursor or Codex and it looks right. Getting it into WordPress normally means copying output, pasting it somewhere, and fixing what broke in transit. Worse, what you paste usually lands as markup nobody can edit afterwards.

UiChemy runs a **Model Context Protocol (MCP) server**, so your AI tool writes into WordPress directly. It builds sections, runs conversions and edits pages on your site, and what arrives is real code in your builder.

**What You Can Move Into WordPress:** Claude to WordPress, Lovable to WordPress, Codex to WordPress, V0 to WordPress, Cursor to WordPress, Google Stitch to WordPress, HTML to WordPress, Wix to WordPress, Clone Site to WordPress.

### How It Works

1. **Generate Your Connection** : The plugin issues a scoped Application Password
2. **Pick Your AI Tool** : Claude Desktop, Cursor, Codex, Antigravity or another MCP client
3. **Add The MCP Config** : Paste the generated block into that tool's config file
4. **Restart And Build** : Ask for a section and watch it appear on the site

### What You Get

- **No Context Switching** : Build and revise pages from the editor you already have open, so the browser is where you check the result, not where you do the work
- **Editable Output** : Sections arrive as real code in your builder, so the next person to touch the page does not need your AI tool
- **Custom Post Types And Fields** : Set up post types and fields through ACF or JetEngine, which covers the scaffolding most client builds start with
- **Agency Repeatability** : One prompt pattern produces the same section across five client sites

== Installation ==

1. Go to **Plugins > Add New** in your WordPress dashboard
2. Search for **UiChemy** and click Install
3. Activate the plugin
4. Open the UiChemy settings page and connect your site using your Site URL and Security Token
5. Pick where you want to build:
    * **From Figma** : Install the UiChemy Figma plugin for your builder (Elementor, Gutenberg or Bricks)
    * **From A Prompt Or Brief** : Start a project at app.uichemy.com, then sign in to the UiChemy plugin with the same UiChemy account
    * **From Your AI Tool** : Open the AI tab, generate your connection, and add the MCP config to Claude, Cursor or Codex
    * **From A Blank Page** : Add the UiChemy Composer widget to any page in Elementor or Gutenberg

== Frequently Asked Questions ==

= What does Build Anywhere, Own It In WordPress mean? =

Build anywhere means the work can start wherever you already are: a written prompt, a client brief, a Figma file, or an AI build from a tool like Claude or Cursor. Own it in WordPress means what comes out is real WordPress content sitting in your own database. Elementor widgets, Gutenberg blocks and Bricks elements you can click and edit, that a client can take over, and that keep serving visitors whatever happens to your account. Nothing renders from our servers and nothing is locked behind a licence check.

= How is this different from an AI site builder? =

Site builders host the result for you, so the site lives on their platform and stops existing if you stop paying. UiChemy writes into WordPress you already own. The output is native Elementor, Gutenberg or Bricks elements in your own database, with your own hosting, your own domain and your own backups. You can move it, sell it, hand it to a client, or keep editing it years later without us involved.

= My last converter produced something nobody could edit. What happens here? =

That is the difference this plugin exists for. Converters and AI builders commonly return an iframe, a locked theme, or a block of markup that technically renders and practically cannot be maintained. UiChemy produces the builder's own elements, so every section is draggable, restylable and editable with the tools your team already knows. Your Figma colours and type arrive as reusable globals rather than inline values, and custom CSS is scoped automatically so it cannot leak into the rest of the site.

= Do I need a Figma file to use UiChemy? =

No. AI Website Creator starts from a written brief instead. Describe the business in a paragraph, review the sitemap it proposes, restyle the pages it designs, then export to WordPress. You can also start from a blank page with the Composer widget and build a section by describing it to Chat AI, or drive the whole thing from Claude or Cursor through AI to WordPress.

= Which page builders does UiChemy support? =

Elementor, including v4 with Atomic Elements and global classes. Gutenberg, including Spectra, Kadence Blocks, GenerateBlocks and Nexter Blocks. And Bricks Builder, with global style classes, padding sync and multi breakpoint container widths. UiChemy Composer, AI Website Creator and AI to WordPress work across all three. AI Express Mode runs on Elementor, and the other two builders use Classic Mode for that path.

= What is the difference between Classic Mode and AI Express Mode? =

Classic Mode is the precision path. You tag Figma layers to specific widgets before exporting, which takes more setup and returns output you can predict to the pixel. It works on Elementor, Gutenberg and Bricks. AI Express Mode is the finishing path. It needs no tagging, reads every layer itself, and applies motion, responsive breakpoints, global colours and type, and your header and footer during the conversion. AI Express Mode runs on Elementor. Classic is not the old way, it is the control option.

= What is UiChemy Composer? =

Composer is one widget that stores real HTML, CSS and JavaScript instead of a panel of settings. Because it holds actual code, anything achievable in HTML and CSS is achievable in it, and AI can read and rewrite the real output rather than toggling options. It is also where the rest of UiChemy lands, so a Figma conversion, an AI Website Creator export and a page built through AI to WordPress all arrive in the same editable place. You work on it three ways: visually in Designer Mode, in code in Developer Mode, or by describing the change to Chat AI.

= How do I hand a finished site to a client without them breaking it? =

Use Designer Mode and Slots. When a design lands in a Composer, UiChemy extracts the editable content automatically, so your client sees numbered text fields, links and image pickers instead of markup. Editing those changes content values only and never touches the structure. On Pro, the Role Manager sets this per WordPress role, so an editor gets content access while the layout stays locked, and White Label removes our branding from the dashboard entirely.

= How do I connect Claude, Cursor or Codex to my site? =

Through AI to WordPress. UiChemy runs an MCP server, the open standard that lets an AI client call external tools. Generate the connection in the plugin, which issues an Application Password, pick your AI tool, paste the config block into that tool's config file, then restart it. You need Node.js 18 or newer, a WordPress Administrator account, and a site reachable over HTTPS. Keep the Application Password private, because it grants admin level write access.

= If I stop paying, do my published pages keep working? =

Yes. Pages are built from real HTML, CSS and JavaScript stored in your WordPress site rather than pulled from our servers, so anything published keeps rendering for visitors. What needs an active plan is new work: running conversions, generating a site in AI Website Creator, or using Chat AI inside Composer.

= Do I need Elementor Pro? =

Not to run conversions. UiChemy works on Elementor Free. Pro is needed in two cases: if your design uses elements that map to Pro only widgets such as forms, navigation menus or sliders, or if you want headers and footers saved as templates during an AI Express Full Setup import. The Plus Addons for Elementor extends the widget range further and is optional.

= Do I need Auto Layout in my Figma file? =

Strongly recommended, and required for AI Express Mode. Auto Layout tells UiChemy how your spacing and alignment are meant to behave, which is what keeps the converted layout stable at other screen sizes. Absolute positioned designs still convert, they just need more adjustment afterwards. The Design Guidelines cover the file structure that converts most cleanly.

= My import does not match the design. What went wrong? =

Almost always the Figma file rather than the conversion. The usual causes are missing Auto Layout, layers nested in a way that does not reflect the visual hierarchy, elements sitting outside the top level frame, negative gaps that CSS Flexbox cannot reproduce, and unflattened masked images. On the WordPress side, check your theme's content width and padding. UiChemy follows your structure faithfully, so a clean file converts accurately.

= Can I edit everything after importing? =

Yes. The import produces native builder elements, so you change text, swap images, restyle, reorder sections, add animation or rebuild the layout entirely using the tools you already know. There are no locked templates, no iframes and no untouchable HTML blocks. If you would rather describe the change than make it, Chat AI writes it for you.

= Can I use UiChemy across multiple client sites? =

Yes. Connect and manage multiple WordPress domains from a single installation, which is how most agencies and freelancers run it. Each site keeps its own connection and you switch between them in the dashboard.

== External Services ==

This plugin connects to the following external services:

**UiChemy Cloud API** : When you export a design from Figma, UiChemy communicates with its cloud API to process and convert your Figma design data into page builder compatible format. Design structure data (frames, layers, styles) is sent during export. No personal data is transmitted.
[Privacy Policy](https://store.posimyth.com/privacy-policy/) | [Terms of Use](https://store.posimyth.com/terms-of-use/)

**Figma API** : UiChemy's Figma plugin reads your design data from Figma to generate the export. This requires the Figma plugin to access your currently open Figma file.
[Figma Privacy Policy](https://www.figma.com/legal/privacy/) | [Figma Terms](https://www.figma.com/legal/tos/)

**jsDelivr CDN** : The composer's "Add library" catalog offers a curated list of popular open-source JavaScript and CSS libraries. When you choose one, UiChemy adds a pinned `cdn.jsdelivr.net` URL to that widget's assets, so visitors to the published page load the file from jsDelivr. Nothing is requested until you add a library, and you can remove or edit the URL at any time. No data about you or your visitors is sent by UiChemy to jsDelivr.
[jsDelivr Privacy Policy](https://www.jsdelivr.com/privacy-policy-jsdelivr-net) | [jsDelivr Terms](https://www.jsdelivr.com/terms)

**Google Fonts** : The same "Add library" catalog offers a list of Google Fonts. Choosing one adds a `fonts.googleapis.com` stylesheet URL to that widget's assets, so visitors to the published page load the font from Google. Nothing is requested until you add a font, and you can remove the URL at any time.
[Google Privacy Policy](https://policies.google.com/privacy) | [Google Terms](https://policies.google.com/terms)
